# Prowl's player rig

Only the greeter uses Prowl. The original `prowl_hytale.blockymodel` and texture remain unchanged in Eternia, and no Aetherhaven asset is edited. `Prowl_PlayerRig.blockymodel` is the playable rig used by `Eternia_Prowl`. It began as a generated rig and was then edited by hand. On September 29, 2026, its current appearance was approved for preservation, including the edited belly and hair, renamed/renumbered meshes, and rounded transforms. It is no longer expected to match the original model exactly.

The generated rig follows the installed Hytale player's bone names and parent hierarchy. Its joint positions follow Prowl's anatomy, with player bone orientations; the pelvis uses the actual hip joint at 50 model units. Original shapes are re-expressed under those bones with inverse parent transforms. Head geometry follows `Head`; the actual neck follows `Neck`; eyes, eyebrows and mouth receive the standard animation target names. Eyelid geometry remains directly on its named bone so native shape-stretch tracks affect it.

Run `python scripts/rig-prowl.py` to export the historical generated version under `build/prowl-generated`, then add `--check` to verify that export's reproducibility. This command never writes active resources. `--assets path/to/Assets.zip` selects a different installed Hytale asset pack. The original proof file describes the historical generated version, not the subsequent manual edits. Generation still compares original shape UVs, geometry and transformed vertices.

`HubNpcIdentityTest` compares the active rig against `src/test/resources/prowl/approved-player-rig.blockymodel`, a frozen copy of the approved artwork. It matches nodes by animation/mesh name, not editor IDs, and checks every shape's geometry, UVs, visibility, parent and JOML world transform. Fixed anatomical coordinates and separate transform tests continue to guard against collapsed proportions. Do not automatically refresh this fixture to make a failing test pass. After an intentional artwork change, review the appearance and animation hierarchy before updating the fixture and native bounds together. The approved active model's SHA-256 is `3c7b94290e340f34548372f941234466f4103062c9baac818797fa4e7f518627`.

Hytale child nodes inherit the parent's **rotated shape offset**, even when the parent shape type is `none`. The initial generator omitted this offset, producing a pelvis at 25 instead of 50 units and overlapping leg/torso meshes. Its initial proof made the same incorrect assumption. The corrected calculation follows native `BlockyModelBoundsParser`: `parent × translation(position) × rotation(orientation) × translation(shape.offset)`. Shape stretch affects only the node's own geometry. Separate regression cases cover shapeless offsets, rotated offsets, and non-inherited stretch. The original and corrected bounds both extend from approximately -0.9365 to 122 units vertically; no overall scale or geometry change conceals the error.

The generator also previews the installed Idle and Walk clips at 13 sample times each. It checks leg segment transforms and standing height, and verifies that the actual eye meshes move under an eye-look clip. These calculations exercise additive animation deltas and catch rig compression; they are not a substitute for the client's exact animation blending and rendering.

Run `node website/scripts/prowl-rig-preview.js` with the website dependencies installed to render the approved fixture and current model through Eternia's actual viewer, using one camera, texture and character scale. It saves `website/test-output/prowl-rig-comparison.png`. If `build/prowl-before.blockymodel` exists, it also includes that saved earlier rig for comparison. The check compares the viewer's resulting bounds; it does not open a game server or use an account.

Native acceptance uses `BlockyModelBoundsParser` on the active rig and compares against fixed bounds independently calculated from the approved artwork's visible vertices. In model units these are min `(-24.8748823865, -0.9364044436, -14.9912)` and max `(26.2203536881, 122, 14.4182541054)`; native units divide by 32. The original model remains available as historical source but is no longer the acceptance reference. The fixture stays in test resources and is not shipped to players.

Native player body animation sets are inherited. Nearby-player head watching and head camera targets are explicit. Passive eye clips target Prowl's new eye/eyebrow bones. Native blink clips are copied with visible eyelid-height changes retargeted from the native seven/five-unit quads at 0.1 bind stretch to Prowl's existing eight/four-unit quads. The texture atlas is untouched. Atlas-specific native talking animations are intentionally not added: their mouth UV offsets refer to Hytale's player atlas and need separate retargeting before they can be used with Prowl's texture.

Connected-client acceptance: observe Prowl at rest and while walking around him; check eyes, blink, head tracking and idle arms; confirm the approved appearance and texture are unchanged. Test the interaction prompt with a rebound Use key. Server asset loading and bind-pose proofs do not substitute for this animation and UI review.
